④ 보조 기능 넷 — 프로젝트 · 아티팩트 · 연결 · 기억

프로젝트

대화 여러 개를 묶는 방. 자료와 지침을 한 번 넣어 두면 그 안의 모든 대화가 그것을 읽고 시작합니다

학원 예: "학부모 안내문" 방에 지난 안내문 10개 + 말투 지침. 팀 플랜이면 이 방을 여섯 명이 같이 씁니다

아티팩트

답변 대신 문서 · 표 · 간단한 웹 화면이 옆에 따로 뜹니다. "여기 고쳐 줘"라고 하면 그 파일이 고쳐집니다

학원 예: 설명회 안내 페이지 초안 · 상담 체크리스트. 링크로 동료에게. 학부모에게 바로 보내는 용도는 아닙니다

연결

구글 드라이브 · 지메일 · 캘린더 · 슬랙을 붙입니다. "지난달 안내문 찾아 줘"가 됩니다

팀 플랜은 관리자가 켜 줘야 멤버가 연결할 수 있고, "읽기만"으로 제한할 수 있습니다

기억 (메모리)

지난 대화를 기억해 다음 대화에 씁니다

팀 플랜은 기본이 꺼짐. 관리자가 켜면 각자 관리하고, 관리자도 남의 기억은 못 봅니다

스킬과 다른 점 프로젝트는 파일을 올려야 보고, 스킬은 폴더를 직접 엽니다. 매달 새 출결표를 올리는 일이 없어지는 쪽이 스킬입니다

# 결석 문자 초안: 이번 주 결석 2회 이상 학생을 뽑아 안내 문자 초안을 만든다

목적  · 매주 월요일, 담당 강사가 학부모에게 보낼 문자 초안을 준비한다
입력  · 출결표 사본 (이름은 번호로 바꾼 것) · 지난주에 보낸 문자 예시 3개
순서  · 1. 출결표를 읽는다  2. 이번 주 결석 2회 이상만 뽑는다  3. 예시 문자와 같은 말투로 초안을 쓴다  4. 번호 · 결석 날짜 · 초안을 표로 만든다
결과  · 표 하나. 한 줄에 학생 하나
하지 않을 것 · 문자를 보내지 않는다. 출결표 원본을 고치지 않는다. 결석 사유를 지어내지 않는다

마지막 줄이 스킬을 안전하게 만듭니다. 보내는 것, 원본 고치는 것, 없는 걸 지어내는 것. 판단은 사람이 하고, 찾고 만드는 일만 AI에게 시킵니다.

Case · 8월 22일 ~ 9월 22일 · 새 스킬 6개 · 그 아래 스크립트 70개

제가 지난 한 달 만든 것 — 넷만

카톡 보내기

목적: 확인한 문구를 카톡 방 하나에 보낸다. 하지 않을 것: 여러 방 반복 · 삭제 · 수정

값어치는 보내는 기능이 아니라 그 앞의 관문 넷입니다. 방 이름 확정 → 문구 전문 보여주기 → 사람이 "예" → 실제 열린 방 제목 대조. 보내는 건 되돌릴 수 없어서 그렇습니다

노트 발행

목적: 원고를 홈페이지 게시판에 올린다. 결과: 올라간 것과 원본이 다른 곳 목록

복붙은 원래 됐습니다. 웹 편집기가 영상 임베드를 글자로 바꿔 놓은 걸 발행 뒤에 발견하고 나서, 발행이 아니라 대조를 스킬로 만들었습니다

팀 취소 처리

목적: 모집이 안 된 팀을 운영에서 뺀다. 입력: 팀 이름 + 시즌 이름은 반드시

같은 팀이 두 시즌에 걸쳐 있으면, 시즌을 안 적었을 때 지금 진행 중인 팀 채널을 건드립니다. 만든 날 취소한 두 팀이 마침 그랬습니다. 그래서 "입력" 칸에 시즌 이름을 필수로 적었습니다

업무일지 구멍 찾기

목적: 자동 기록이 놓친 날을 찾는다. 결과: 날짜별로 빠진 일 목록. 오늘 아침에 만들었습니다

파일을 고칠 때만 자동으로 적히니 "확인만 한 날"이 통째로 비었습니다. 한 달치 대화 264개 중 98개가 일지에 없었고, 일에 해당하는 38개를 채웠습니다. 하지 않을 것: 개인 일은 안 적는다

넷 다 같은 모양입니다 다섯 칸. 그리고 넷 다 "하지 않을 것"이 사고 한 번 뒤에 생겼습니다. 처음부터 완벽한 칸은 없습니다. 오늘 만드는 것도 그렇습니다
