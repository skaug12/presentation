# 발표 아카이브

이슬기가 진행한 발표 자료 모음입니다. 목록: <https://skaug12.github.io/presentation/>

## 정본은 여기가 아닙니다

배포용 HTML 만 둡니다. 고칠 때는 옵시디언 `Memo` 보관함의 소스를 고치고 다시 생성합니다.

| 덱 | 정본 | 고치는 법 |
|---|---|---|
| 새 덱 (26여름 5회차~) | `Memo/3 콘텐츠/발표/AI부사수/{시즌}-{회차}-{트랙}.md` | 소스 수정 후 `make_deck.py` 재생성 |
| 과거 덱 | 배포된 HTML | `Memo/…/AI부사수/_content/<덱>.md` 수정 후 `deck_content.py inject` |

색인: `Memo/3 콘텐츠/발표/_발표목록.md`

## HFK 배포본과의 관계

AI부사수 덱은 멤버에게 `thehfk.github.io/hfk-ai-bss/` 주소로 공유돼 있습니다.
그 주소는 이 아카이브로 넘겨주는 리다이렉트로 살려둡니다. 멤버가 보는 목록
(발표 + FAQ + 트렌드)은 계속 `thehfk/hfk-ai-bss` 가 맡습니다.
