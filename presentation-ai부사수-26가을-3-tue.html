Trend 1 · Anthropic · 9월 22일 ~ 10월 7일

클로드 5.5 세 가지가 3주 사이에 모두 나왔습니다

1회차에 말씀드린 대로 Opus · Sonnet · Haiku는 크기가 다른 같은 Claude입니다. 이번에 세 크기가 모두 5.5로 바뀌었습니다.

Opus 5.5 · 9월 22일

가장 큰 모델입니다. 오래 걸리는 일, 여러 단계를 이어서 하는 일에 씁니다.

2회차 일주일 전에 나왔습니다. 이전 Opus 5보다 빠르고 값이 내려갔습니다.

Sonnet 5.5 · 9월 28일

중간 크기입니다. 앤트로픽 발표로는 Sonnet 5보다 30% 빠르고, 대부분의 일에서 비용이 최대 30% 적습니다.

claude.ai 채팅에서 가장 많이 쓰는 크기입니다.

Haiku 5.5 · 10월 7일

가장 작고 빠른 모델입니다. 앤트로픽은 같은 일을 많이, 자주 돌리는 작업용이라고 소개했습니다.

같은 날 클로드 코드 변경 기록에도 Haiku 5.5가 올라왔습니다.

① 사원급과 무슨 상관인가 순서가 정해진 반복 업무는 큰 모델이 필요 없는 경우가 많습니다. 작은 모델은 빠르고 사용량도 덜 씁니다. 클로드 코드 채팅창에 /model 을 적으면 지금 쓰는 모델이 보이고 바꿀 수 있습니다. 오늘은 기본값 그대로 두고, 스킬이 세 번 맞게 돈 다음에 작은 모델로 바꿔 봅니다.

Trend 2 · OpenAI · 10월 7일

챗GPT가 GPT-6로 바뀌고, 답이 화면으로 나옵니다

10월 7일부터 챗GPT의 기본 모델이 GPT-6로 바뀌었습니다. 무료 사용자도 씁니다. 유료(Plus 이상)는 GPT-6 Sol, 무료는 GPT-6 Luna입니다.

Intelligent UI

질문에 맞춰 답의 모양을 챗GPT가 고릅니다.

  • 비교를 물으면 좌우로 나란한 표
  • 원리를 물으면 눌러 볼 수 있는 그림
  • 계산이 필요하면 대화창 안에 계산기 · 더치페이 계산기

쉬운 질문에는 그냥 글로 답합니다. 생각을 다 끝내기 전에 답을 먼저 보여주기 시작합니다.

클로드 코드로 하는 것과 다른 점

챗GPT 화면에 나온 표는 그 대화 안에 있습니다. 다음 주에 같은 표가 필요하면 다시 물어야 합니다.

클로드 코드가 만든 표는 워크스페이스에 파일로 저장되고, 다음 주 스킬이 그 파일을 다시 읽어 지난주와 비교합니다.

한 번 묻는 일과 매주 하는 일은 도구가 다릅니다 한 번 궁금한 것은 챗GPT의 보기 좋은 답이 편합니다. 매주 돌아오는 일은 지난번 결과가 파일로 쌓이는 쪽이 빨라집니다. 오늘 만드는 ① 사원급은 뒤쪽입니다.

Trend 3 · Google · Anthropic · 10월 6일 ~ 9일

무료로 쓰던 좋은 모델이 줄어들고 있습니다

같은 주에 두 회사가 요금제를 바꿨습니다. 방향은 같습니다. 좋은 모델은 유료로, 대신 쓰는 양은 늘려 준다.

제미나이 · 10월 9일부터

  • 무료: Flash와 Pro를 못 씁니다. 가장 작은 Flash-Lite만 씁니다
  • AI Plus (월 $4.99): Pro가 빠집니다. 시점은 메일로 따로 안내
  • AI Pro (월 $19.99): 그대로이고, 상위 요금제에만 있던 Deep Think가 추가됩니다

회사 계정에서 제미나이를 무료로 쓰던 분은 이번 주부터 답의 수준이 달라졌을 수 있습니다.

클로드 스타트업 프로그램 · 10월 6일

  • 대상: 설립 5년 이내이거나, 최근 2년 안에 투자를 받은 회사
  • 혜택: Claude 팀 플랜 1년 무료(프리미엄 좌석 최대 5개) + API 크레딧 $1,000
  • 신청: claude.com/programs/startups

해당하는 회사에 다니시는 분은 대표님께 이 장을 보여드려도 됩니다.

회사에 비용을 요청할 때 필요한 숫자 '편해졌다'로는 결재가 나지 않습니다. pp-매트릭스.md 에 적은 '한 번에 몇 분' × '한 달에 몇 번'이 줄어든 만큼이 근거가 됩니다. 오늘 실습 끝에 이 숫자를 적는 이유입니다.

Trend 4 · 클로드 코드 공식 문서 · 10월 6일 업데이트

반복 업무를 시간에 맡기는 방법이 세 가지 있습니다

'매주 월요일 9시에 /주간일정 돌려줘'를 걸어 두는 기능입니다. 10월 6일 업데이트로, 예약 실행 중에 만든 결과 페이지(아티팩트)는 묻지 않고 나만 보는 페이지로 올라가게 바뀌었습니다. 아침에 결과 링크만 열어 보면 됩니다.

/loop · VS Code 안에서

채팅창에 /loop 1h 받은편지함에서 답장 안 한 메일 정리해줘처럼 적습니다.

VS Code 창이 열려 있는 동안만 돕니다. 반복 예약은 7일 뒤 저절로 꺼집니다.

데스크톱 앱 · 내 컴퓨터에서

Code 탭 → Routines → New routine → Local. 매일 · 평일 · 매주 중에 고릅니다.

앱이 켜져 있고 컴퓨터가 깨어 있어야 합니다. 잠자는 동안 놓친 것은 깨어날 때 한 번만 돌립니다.

클라우드 · 컴퓨터가 꺼져 있어도

같은 Routines 화면에서 클라우드로 만듭니다. 노트북을 닫아도 돕니다.

대신 내 컴퓨터의 파일은 못 읽습니다. 간격은 최소 1시간입니다.

오늘은 예약을 걸지 않습니다 틀리는 스킬을 예약하면 틀린 결과가 매주 쌓입니다. 스킬이 실제 파일 세 건에서 세 번 다 맞은 뒤에 겁니다. 빠르면 4회차 끝에 같이 걸어 봅니다.

Tool 1 · Codex · 2회차 Tips 장에서 한 줄로 말씀드린 것

Codex를 VS Code에 같이 설치해 두 번째 검토자로 씁니다

설치 두 가지

  • VS Code 확장: 확장 탭에서 'Codex' 검색 → 게시자가 OpenAI인 것 설치 → ChatGPT 계정으로 로그인
  • CLI: VS Code 터미널에 npm install -g @openai/codex → codex 로 로그인 (윈도우는 npm.cmd)

확장만 있으면 Codex 창에서 따로 쓰고, CLI까지 있으면 클로드 코드가 Codex를 불러 씁니다. 오늘 소개하는 것은 뒤쪽입니다. ChatGPT 유료 플랜이 필요합니다.

(가) 엉뚱한 사람에게 · 9월 4일

행사 도착 체크 메시지를 보내는 스크립트가 공지 명단과 신청 폼을 이름으로 맞추고 있었습니다.

재현: 공지 명단과 폼에 같은 이름의 다른 사람이 있으면, 실제 신청자가 아닌 사람에게 메시지가 갑니다.

재현: 메일 서버가 이미 받아 놓고 응답 직전에 연결이 끊기면, 같은 사람이 메일을 두 번 받습니다.

Tool 2 · Orca · onorca.dev

Orca는 같은 일을 여러 에이전트에게 동시에 맡깁니다

Y Combinator가 투자한 Stably AI가 만든 무료 오픈소스 데스크톱 앱입니다. 클로드 코드 · Codex · 제미나이 등 터미널에서 도는 에이전트를 한 화면에 띄웁니다. 결제는 각자 쓰던 구독 그대로입니다.

일마다 작업 공간을 나눕니다

작업 하나마다 폴더 사본(워크트리)을 따로 만들어, 두 에이전트가 같은 파일을 동시에 고쳐도 섞이지 않습니다.

그래서 워크스페이스가 깃(Git) 폴더여야 합니다. '이 폴더를 깃으로 관리하게 해줘'로 시작합니다.

폰으로 확인합니다

iOS · 안드로이드 앱으로 에이전트가 지금 무엇을 하는지, 사용량이 얼마나 남았는지 봅니다.

2회차에 본 /remote-control과 비슷하지만, 여러 에이전트를 한 번에 봅니다.

비교해서 고릅니다

같은 프롬프트를 여러 에이전트에 보내고, 결과를 함께 열어 보고 나은 쪽만 가져옵니다.

고친 내용(diff)을 앱 안에서 바로 확인합니다.

예시 · 고객사 리포트 첫 양식 정하기
'지난달 광고 CSV로 고객사 월간 리포트 초안을 만들어줘'를 클로드 코드와 Codex에 동시에 보냅니다. 20분 뒤 두 초안을 양쪽에 열어, 표 구성은 이쪽, 요약 문장은 저쪽을 골라 스킬의 '내놓는 것' 줄에 적습니다. 양식이 정해지면 그다음부터는 스킬 하나로 돌립니다.

언제 꺼내나 스킬이 세 개 이상 돌고, 깃이 익숙해진 뒤입니다. 6회차 '스킬을 묶어 에이전트로'에서 다시 봅니다.

Tool 3 · Headroom · github.com/headroomlabs-ai/headroom

Headroom은 클로드가 읽을 양을 먼저 줄여 줍니다

2회차 Tips 장에서 '클로드는 질문할 때마다 대화 전체를 다시 읽는다'고 했습니다. Headroom은 그 사이에 서서, 긴 검색 결과 · 로그 · 표 데이터를 모델에 보내기 전에 내 컴퓨터에서 압축합니다. 원본은 내 컴퓨터에 두고, 필요하면 다시 꺼내 읽습니다.

설치와 실행 · 터미널

  • 설치: pip install "headroom-ai[all]" (파이썬 3.10 이상)
  • 실행: headroom wrap claude → 압축을 거치는 클로드 코드가 터미널에 뜹니다
  • 얼마나 아꼈나: headroom savings
  • 되돌리기: headroom unwrap claude

VS Code 확장 패널이 아니라 VS Code 터미널의 claude에 붙습니다.

얼마나 줄어드나 · 만든 쪽 측정치

  • JSON 같은 표 데이터: 60~95%
  • 폴더 전체 훑어보기: 42%
  • 코드 검색 결과: 21%
  • 사람이 쓴 문장: 거의 안 줄어듭니다

같은 모양이 반복되는 내용일수록 많이 줄어듭니다. 내 작업에서는 savings 명령으로 직접 확인합니다.

예시 · 메일 정리 스킬이 한도에 자주 걸릴 때
'지난 3개월 받은 메일 중 견적 메일만 표로' 같은 스킬은 2회차에 설치한 gws가 메일 수백 통을 JSON으로 가져옵니다. 가장 많이 줄어드는 종류입니다. 같은 스킬을 headroom wrap claude 로 띄운 창에서 돌리고, savings로 몇 % 줄었는지 봅니다.

언제 꺼내나 한 주에 두 번 이상 사용량 한도에 걸릴 때입니다. 그 전에는 2회차 팁(새 대화, 범위 좁히기)이 먼저입니다.

Tool 4 · Aside · aside.com

Aside는 로그인해 둔 사이트에서 AI가 대신 누릅니다

크롬 기반의 AI 브라우저입니다. 연결 방법(API)이 없는 관리자 화면도, 내가 로그인해 둔 탭이면 AI가 직접 열고 입력합니다. 비밀번호는 브라우저가 채우고 AI에게는 보여주지 않습니다. 쓰던 Claude · ChatGPT 구독을 연결해 씁니다.

제 예시 1 · 알림톡 템플릿 56개 · 9월 13일

아임웹 알림톡 템플릿은 관리자 화면에서 한 개씩 손으로 만드는 방법밖에 없습니다. 문안은 클로드 코드로 쓰고, 클로드 코드가 Aside에 열어 둔 로그인 탭을 이어받아 56개를 입력했습니다.

로그인은 제가 직접 했고, 아임웹 비밀번호는 어디에도 저장하지 않았습니다.

제 예시 2 · 레터 썸네일 · 10월 8일

피그마 연결 도구(MCP)는 무료 플랜 호출 한도와 폰트 문제로 글자를 못 고쳤습니다. 클로드 코드가 Aside 탭에 열린 피그마를 이어받아 템플릿 복제 → 제목 교체 → PNG 저장까지 했습니다.

원본 프레임은 건드리지 않고 항상 복제본에서. 스킬의 '하지 않을 것' 줄 그대로입니다.

여러분 예시 · 2회차 4L의 '회사 일은 먼데이닷컴에서'
Aside에서 먼데이닷컴 보드를 열어 둔 채 '이번 주 마감 항목만 담당자 · 마감일로 표를 만들어 CSV로 내려받아줘'. 내려받은 CSV를 워크스페이스에 넣으면 그 뒤는 오늘 만드는 클로드 코드 스킬이 이어받습니다.

회사 계정은 보안 규정부터 화면 내용이 AI 서버로 전송되는 것은 클로드 코드와 같습니다. 1회차 '넣지 않는 것' 기준을 그대로 지키고, 보내기 · 결제 · 삭제 버튼은 사람이 누릅니다.

# 주간광고리포트: 광고 관리자 CSV로 주간 보고서의 숫자 칸을 채운다

읽는 것  · 이번 주에 내려받은 광고 CSV 하나 · 지난주 보고서 파일
대조  · 지난주 보고서의 숫자 (증감을 계산한다) · 보고서 양식의 칸 이름
내놓는 것  · 숫자를 채운 이번 주 보고서 사본 하나 + 가장 크게 변한 항목 세 줄 메모
묻는 곳  · 보고서 칸 이름이 CSV에 없으면 멈추고 묻는다
하지 않을 것 · 원본 보고서를 고치지 않는다. 없는 숫자를 짐작해 채우지 않는다. 보고서를 보내지 않는다

마지막 줄이 사원급을 안전하게 만듭니다 AI가 가장 자주 틀리는 곳은 없는 숫자를 그럴듯하게 채우는 것입니다. '짐작해 채우지 않는다'를 적어 두면, 빈칸은 빈칸으로 두고 나에게 묻습니다. 판단은 사람이 하고, 찾고 옮기는 일만 맡깁니다.
