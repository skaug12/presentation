Tool 1 · Codex

Codex는 클로드가 만든 결과를 한 번 더 확인합니다

Codex는 챗GPT를 만든 OpenAI의 AI입니다. VS Code에 클로드 코드와 함께 설치해 두면, 클로드가 만든 결과를 다른 회사의 AI가 한 번 더 확인합니다. 같은 AI는 같은 곳에서 틀리기 쉬워서, 다른 AI에게 맡기면 놓친 곳이 잘 보입니다.

설치 방법

  • VS Code 왼쪽의 확장 탭에서 'Codex'를 검색하고, 게시자가 OpenAI로 표시된 확장 프로그램을 설치합니다.
  • VS Code 아래쪽 터미널 창에 npm install -g @openai/codex 를 입력하면, 클로드 코드가 Codex를 직접 불러서 씁니다.

챗GPT 유료 요금제가 있어야 합니다.

제 예시

9월에 외부 고객에게 보여 줄 분석 자료를 클로드 코드로 만들었습니다. 그리고 Codex에게 '반대 입장에서 틀린 곳을 찾아 달라'고 맡겼습니다.

결론은 맞았지만, 근거로 쓴 문장 세 곳이 틀려 있었습니다. 고객 앞에서 발견됐다면 결론까지 의심받았을 것입니다.

이렇게 시킵니다 클로드 코드에 'Codex에게 이 보고서의 숫자를 원본 파일과 비교해서 틀린 곳만 알려 달라고 해줘. 파일은 고치지 말고.'라고 적습니다.

Tool 2 · Aside · aside.com

Aside는 AI가 화면을 직접 눌러 일하는 인터넷 브라우저입니다

크롬처럼 쓰는 인터넷 브라우저인데, 안에 AI가 들어 있습니다. 내가 로그인해 둔 사이트에서 AI가 메뉴를 누르고 글자를 입력합니다. 비밀번호는 브라우저가 채우고, AI에게는 보여주지 않습니다. 쓰고 있는 클로드나 챗GPT 요금제를 연결해서 씁니다.

제 예시 1 · 알림톡 문구 56개 등록 · 9월 13일

홈페이지 관리자 화면에서 알림톡 문구를 하나씩 손으로 등록해야 했습니다. 문구는 클로드 코드로 쓰고, 등록은 Aside가 관리자 화면에서 56개를 차례로 입력했습니다.

로그인은 제가 직접 했고, 비밀번호는 어디에도 저장하지 않았습니다.

제 예시 2 · 레터 썸네일 · 10월 8일

디자인 프로그램인 피그마에서 지난 썸네일을 복사하고, 제목 글자만 바꿔 이미지로 저장하는 일을 Aside에 맡겼습니다.

원본은 건드리지 않고, 항상 복사본에서만 작업하게 했습니다.

여러분이라면 먼데이닷컴이나 노션처럼 로그인해야 보이는 화면에서 '이번 주가 마감인 일만 담당자와 마감일로 표를 만들어 엑셀로 내려받아줘'라고 시켜 볼 수 있습니다. 회사 계정에 쓰기 전에는 회사 보안 규정을 먼저 확인합니다.

Tool 3 · Tool 4 · Orca · Headroom

Orca와 Headroom은 개발자들이 많이 쓰는 도구입니다

두 가지 모두 무료이고, 터미널 명령에 익숙해진 뒤에 쓰는 도구입니다. 지금은 이름과 쓰임새만 알아 두시면 됩니다.

Orca · 여러 AI에게 같은 일을 동시에

클로드 코드와 Codex 같은 여러 AI를 한 화면에 띄워 놓고, 같은 일을 동시에 맡긴 뒤 결과를 비교하는 프로그램입니다. 휴대폰 앱으로 진행 상황도 확인합니다.

예시: '지난달 광고 숫자로 고객사 월간 보고서 초안을 만들어줘'를 클로드와 Codex에 동시에 맡깁니다. 두 초안을 비교해서 표는 한쪽 것을, 요약 문장은 다른 쪽 것을 고릅니다.

Headroom · 사용량 아끼기

클로드가 긴 자료를 읽기 전에 내 컴퓨터에서 먼저 내용을 줄여서 사용량을 아끼는 프로그램입니다. 만든 회사가 측정한 결과, 표로 된 자료는 60~95%까지 줄었습니다. 사람이 쓴 문장은 거의 줄지 않습니다.

예시: 지난 3개월 동안 받은 메일 수백 통에서 견적 메일을 찾는 일처럼, 읽을 양이 많아 사용량 한도에 자주 걸릴 때 씁니다.

실습 1 · 고르기 · 10분

1. 맡길 일을 하나 고릅니다

일정 정리

'이번 주 캘린더 일정을 날짜별로 정리하고, 회의마다 준비할 것을 한 줄씩 적어줘'

메일 정리

'지난주에 받은 메일 중 아직 답장하지 않은 것만 보낸 사람, 제목, 날짜로 표를 만들어줘'

보고서 숫자 채우기

'이번 주 광고 성과 파일을 보고, 주간 보고서에 지난주보다 늘거나 줄어든 숫자를 채워줘'

개인 일

'이번 달 카드 명세서를 식비, 교통, 구독으로 나눠 합계를 내줘'

고르는 기준 남에게 보내지 않는 일, 지금 이 컴퓨터에 파일이 있는 일, 20분 안에 끝나는 일을 고릅니다. 회사 파일은 이름과 연락처를 지운 사본으로 씁니다.

실습 2 · 스킬 만들기 · 30분 · 그대로 복사해서 붙여 넣기

2. 이 문장을 붙여 넣으면 스킬이 만들어집니다

클로드 코드가 하나씩 질문하면, 여러분은 답만 하면 됩니다.

'(고른 업무 이름)'을 AI에게 맡기는 스킬을 만들려고 합니다.
저와 인터뷰하면서 아래 다섯 가지를 채워 주세요. 질문은 한 번에 하나씩 해 주세요.
 1. 무엇을 읽는지  2. 무엇과 비교하는지  3. 무엇을 만드는지  4. 어디서 저에게 물어야 하는지  5. 절대 하지 않을 것
다 채우면 저장하기 전에 내용을 먼저 보여 주시고, 제가 '예'라고 하면 스킬로 저장해 주세요.
원래 파일은 고치지 말고, 결과는 항상 새 파일로 만들어 주세요.

저장한 뒤에 확인할 것 왼쪽 폴더 목록에서 SKILL.md 파일을 열고, 5번 '절대 하지 않을 것'이 적혀 있는지 봅니다. 비어 있다면 '없는 숫자를 짐작해서 채우지 않는다'처럼 직접 한 줄을 적습니다.

실습 3 · 실행과 확인 · 30분

3. 실행하고 결과를 확인합니다

결과 파일을 직접 엽니다

AI가 '완료했습니다'라고 해도, 숫자 하나는 원래 파일과 직접 비교해 봅니다.
