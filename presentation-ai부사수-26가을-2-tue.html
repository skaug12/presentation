Security · 1회차 마지막 장, 다시

설치 전에 한 번 더 — 무엇을 넣지 않나

1회차에 "설치 전에 알아둘 것"으로 보신 장입니다. 클로드 코드는 내 컴퓨터에서 돌지만 읽힌 내용은 Claude 서버로 전송됩니다. 이제 진짜 내 파일을 여니까 다시 봅니다.

말해도 되는 것

  • "매출 시트에 컬럼이 다섯 개 있어" (구조만)
  • "이 엑셀을 월별로 분류해줘" (작업 요청)
  • "마케팅 카피 초안 써줘" (콘텐츠)
  • "경쟁사 가격 비교해줘" (공개 정보)

넣지 않는 것

  • 고객 개인정보 (이름 + 전화번호 + 주소)
  • 사내 시스템 비밀번호 · API 키
  • 미공개 재무 · 인사 정보
  • 주민번호 · 카드번호 · 계좌번호

회사 파일로 해 보고 싶다면 원본 대신 이름을 번호로 바꾸고 연락처를 지운 사본을 워크스페이스에 넣습니다. 비밀번호는 1회차에 본 .env 보관 파일 방식으로, 대화에는 남기지 않습니다. 회사 보안 규정이 우선이라, 애매하면 오늘은 개인 파일로 하셔도 됩니다.

이 파일은 제가 구글에 등록해 둔 프로그램 등록증입니다. 비밀번호가 아니라서 이 파일로는 남의 메일을 못 봅니다. 로그인은 각자 자기 계정으로 합니다.

단계맥윈도우
1 · Node.js 설치nodejs.org → LTS 버튼 → 받은 .pkg 열고 "계속"nodejs.org → LTS 버튼 → 받은 .msi 열고 "Next"
2 · 터미널 열기VS Code를 ⌘Q로 완전히 끄고 다시 열기 → 메뉴 터미널 → 새 터미널VS Code 창을 전부 닫고 다시 열기 → 메뉴 터미널 → 새 터미널
3 · 설치 명령sudo npm install -g @googleworkspace/cli
맥 비밀번호를 칩니다. 화면에 안 보여도 입력되고 있습니다		npm.cmd install -g @googleworkspace/cli
npm 뒤에 .cmd를 꼭 붙입니다

2단계에서 VS Code를 다시 켜는 이유 Node.js를 깔기 전에 연 창은 새 프로그램을 모릅니다. 껐다 켜야 3단계 명령을 알아듣습니다.

Pattern · 반복도 1위 ~ N위

"달력에 제일 자주 다시 나타나는 것"이 1위

매일 > 매주 > 매달 > 분기 > 1년에 몇 번 > 한 번. 같은 주기면 한 번에 더 오래 걸리는 것이 앞

Potential · 경험 1위 ~ N위

"안 보고도 할 수 있는 것"이 1위

눈 감고 하는 것 > 순서는 아는데 확인하며 하는 것 > 매번 찾아보는 것 > 해 본 적 없는 것(미뤄 둔 일)

가운데서 가릅니다

스무 개면 10위를 기준으로 앞은 "높음", 뒤는 "낮음"
